## Take-Home Engineering Challenge: Implement website

### Overview
Based on the provided interface for **NestFind**—our platform for finding apartments, studios, and homes—we want to transition from a static search application into a working website. 

Your objective is to design and develop the website.

---

### Key Requirements & SDLC Scope
To successfully complete this challenge, you are expected to navigate the entire Software Development Life Cycle (SDLC):

* **Product & Scope Definition:** Define the exact problem your AI feature solves. Document your assumptions, user intent, and why you chose this specific implementation.
* **Architecture & System Design:** Design the system architecture. Specify how the system operates, manages state, handles platform data (e.g., listings, cities, prices), and interacts with external APIs.
* **Implementation:** Build a working prototype. You may choose your own technical stack (Frontend, Backend, Database, and AI Framework/SDKs). 
* **Testing & Validation:** Demonstrate how you verify AI's outputs, functional and non-functional requirements, and business logic.
* **Evaluation & Future Roadmap:** Provide a brief summary detailing how you would scale this feature, monitor agent performance in production, and handle edge cases.

---

### Deliverables
1.  A short README detailing your product rationale, architecture diagram, and setup instructions.
2.  A link to the source repository or attach the source code files.
3.  A brief video walkthrough (max 3 minutes) demonstrating the end-to-end user flow.

Good luck!
